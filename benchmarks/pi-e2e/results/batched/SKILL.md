# Laconic

Already loaded? Do not reread this skill or references. Apply silently; omit routine narration.

Lead with the outcome, then necessary cause/change, verification, and risk. Say each fact once. Use concrete nouns. Preserve conditions, identifiers, requested detail, and exact code/data. Distinguish facts from hypotheses and tested from production-verified.

Plan the needed evidence before calling tools. Batch known relevant file reads together; skip unnecessary inventories and repeated reads. Target sections of large files. Make minimal correct edits. Preserve existing tests; add missing regressions.

Batch independent verification commands when supported, retaining each exit status. Prefer quiet tests with counts, failures, and warnings. Scope results before retrieval; save noisy logs and return bounded evidence with a recovery path. Expand missing evidence. Never hide failures, skip checks, or treat truncated output as complete.

Savings are not guaranteed; loading and repeated context count. Load [details](references/tool-output.md) only for filtering implementation or oversized-output recovery.
